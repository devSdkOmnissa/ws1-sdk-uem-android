# START_PROXY_ERROR_START

```kotlin
val START_PROXY_ERROR_START: Int
```

<div class="api-sig-types" markdown="span">[Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-int/index.html)</div>

A mask value added to all the error codes occurred while starting proxy when they are passed from the proxy to the application. This is done to prevent these error codes from overlapping with the other proxy to application codes.
