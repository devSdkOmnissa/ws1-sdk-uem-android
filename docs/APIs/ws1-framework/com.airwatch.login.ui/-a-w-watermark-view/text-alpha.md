# textAlpha

```kotlin
var textAlpha: Float
```

<div class="api-sig-types" markdown="span">[Float](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-float/index.html)</div>

Denotes the watermark text opacity in percentage. The default value is 20% (0.2f). The value should be between 20% (0.2f) and 100% (1.0f).
